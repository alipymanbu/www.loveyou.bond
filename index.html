01 · Engine

会自己重新平衡的分段

传统下载器在任务开始前把文件切成固定几段；FluxDown 把切分放到了运行时。某条连接提前跑完，引擎就把仍在传输中最慢的分段对半拆开、接管后半截——任何一个慢镜像都拖不住整个下载。

  • 01按需切分 — 连接数逐步爬升，只在服务器承受得住时加码。
  • 02互助抢速 — 空闲连接把最大的在传分段对半拆开，接手救援。
  • 03连接复用 — 长连接在分段之间复用，省去重复握手。
  • 04按域名学习 — 每个主机的连接上限与起步提示都会被记住。

02 · Protocols

六种协议，一条队列

每种协议都有专属下载器，同在一个 Rust 引擎里——共享队列、限速、重试、分类和续传状态。粘贴链接后自动识别类型，不用先选协议。

P/01 · segmented

HTTP / HTTPS

Range 请求与动态分段，支持 Cookie、自定义请求头与代理，是最常用的直链下载方式。

P/02 · resumable

FTP

传统文件服务器，支持断点续传，与其他任务在同一队列里调度。

P/03 · magnet · DHT

BitTorrent

磁力链接与 .torrent 种子，可逐个勾选文件，支持补充 Tracker 列表（DHT / UPnP）。

P/04 · m3u8 · AES-128

HLS 流媒体

粘贴 .m3u8 清单即可：选画质、并行抓分片、自动解密 AES-128，最后合并成单个文件。

P/05 · audio + video

DASH 流媒体

.mpd 清单的音轨与视频轨分开下载，结束后自动合并（需系统装有 ffmpeg）。

P/06 · server · Kad

eD2K 电驴

ed2k:// 链接经服务器列表与 Kad 网络下载，自带哈希校验；移动端入口以所用版本界面为准。

03 · Integration

浏览器把下载交给它

桌面端配有 Chrome / Edge / Firefox 浏览器扩展：三层拦截引擎在浏览器保存文件之前接管下载，自动嗅探网页里的 HLS / DASH 流媒体资源，并把 Cookie 与 Referer 一并带过去；也可以在扩展里按文件类型智能过滤，需要临时绕过时 Alt+Click 即可。

更进一步，FluxDown 内置了 MCP（Model Context Protocol）服务端——Claude、Cursor 等 AI 客户端可以直接新建、监控与控制下载任务。

界面也是新的：桌面端已切换为 GPUI 原生窗口（2026-09-30 公告）——没有 WebView、没有 Electron；关到托盘后传输照跑，再打开窗口立即接上实时状态。

同一套引擎覆盖多个平台，界面提供深浅主题与 13 套配色，三栏布局可调：

Windows macOS Linux Android（APK） NAS · Docker 命令行 CLI 浏览器扩展

05 · FAQ

常见问题

FluxDown 收费吗？会有广告吗？

它是 AGPL-3.0 协议下的开源项目，零广告、零追踪、无需账号，数据完全留在本地。项目把它定位成 IDM 的免费开源替代品。

手机上能下 BT 磁力吗？为什么经常没速度？

能，磁力链接与 .torrent 种子都支持。BT 速度取决于资源有没有人在做种，跟带宽关系不大；另外把 FluxDown 加进电池白名单，避免安卓后台清理掐断连接。

网页视频（m3u8）怎么下载？

把 .m3u8 清单地址粘进新建任务，引擎会自动抓全部分片、解密并合并成完整视频。DRM 加密的付费视频与需要登录态的地址下不了。

支持哪些链接格式？

HTTP/HTTPS 直链、FTP、magnet 磁力、.torrent 种子、.m3u8 与 .mpd 清单；桌面端还支持 ed2k:// 电驴链接。粘贴后自动识别类型。

下载速度不理想怎么排查？

先看两处：设置里的线程数有没有被调小过、全局限速有没有开启。直链任务换镜像源或错峰下载最有效；BT 任务主要看资源热度。更多排查思路见获取指引页。
